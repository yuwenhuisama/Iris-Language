# Iris v1 Migration And Divergence Ledger

Status: Iris v1 draft, frozen semantics.

IRIS-V1-MIGRATION-C001: This chapter is the sole Iris v1 ledger for intentional source and behavior divergences from Legacy Iris. Each migration row MUST record legacy evidence, v1 replacement, rationale, migration example, and one disposition tag: `preserve`, `intentional-divergence`, `removed`, or `deferred`.

IRIS-V1-MIGRATION-C002: Historical files are migration evidence only. The PDF, Notepad++ highlighter, legacy scripts, generated parser output, and old implementation behavior MUST NOT become normative unless a frozen decision and a normative v1 chapter adopt the behavior.

IRIS-V1-MIGRATION-C003: A behavior supported only by `legacy/Document/Iris Programming Language Intro.pdf` MUST NOT be tagged `preserve` without corroboration from frozen decisions plus either legacy scripts, implementation behavior, or an explicit v1 replacement clause. PDF-only evidence can justify `removed`, `intentional-divergence`, or `deferred`, but not preservation.

IRIS-V1-MIGRATION-C004: Migration tools SHOULD diagnose removed Legacy Iris syntax with row IDs from this chapter when the syntax is recognizable. A diagnostic that names the row still MUST point users to the v1 replacement clause rather than treating the historical syntax as accepted source.

IRIS-V1-MIGRATION-C005: This chapter does not reserve historical words. Reserved keywords and historical non-keywords are owned by [02-lexical-grammar.md](02-lexical-grammar.md), especially `IRIS-V1-GRAMMAR-C013` and `IRIS-V1-GRAMMAR-C014`.

IRIS-V1-MIGRATION-C006: The ledger row IDs below are stable migration IDs. Do not renumber existing rows. Add new rows with the next unused `IRIS-V1-MIG-<nnn>` ID.

## Disposition Tags

IRIS-V1-MIGRATION-C007: The following disposition tags are normative for this ledger:

| Tag | Meaning |
| --- | --- |
| `preserve` | Iris v1 preserves the legacy intent or behavior under a current v1 surface. Source spelling may still change when the replacement clause says so. |
| `intentional-divergence` | Iris v1 keeps the underlying language goal but changes source syntax, semantics, failure behavior, or static contract. |
| `removed` | Iris v1 provides no accepted source form or permanent alias for the legacy behavior. |
| `deferred` | Iris v1 does not define the behavior, but the area may be reconsidered by a future language version or standard package. |
