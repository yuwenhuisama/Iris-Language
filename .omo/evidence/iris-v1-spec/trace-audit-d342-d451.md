## Ownership Notes

Selector suffix syntax belongs to `GRAMMAR`; property dispatch and truthiness protocol belong mainly to `RUNTIME`; assignment expression, callable, binding, loop, and match behavior belong mainly to `CONTROL`; text, binary, Symbol, Regex, hash value behavior, and the core text-to-binary conversion rows belong mainly to `COLLECTIONS`. `LIBRARY` clauses refine `D-413` and `D-414` for Encoding surfaces, but they are not the primary owner for these rows.

The current broad traceability vectors remain useful as chapter smoke tests, but this audit rejects them as final trace coverage for these rows unless the table names them as directly relevant.
